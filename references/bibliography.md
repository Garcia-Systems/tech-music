# Project bibliography

Entries below were inspected for the model chapter unless explicitly marked as a source-plan item.

## Inspected sources

1. Python Software Foundation. “`wave` — Read and write WAV files.” *Python 3.14.2 documentation*. <https://docs.python.org/3/library/wave.html>. Accessed 2026-08-21. (PCM WAV writing API and parameters.)
2. NumPy Developers. “`numpy.sin`.” *NumPy v2.4 Manual*. <https://numpy.org/doc/stable/reference/generated/numpy.sin.html>. Accessed 2026-08-21. (Elementwise sine in radians.)
3. NumPy Developers. “`numpy.arange`.” *NumPy v2.4 Manual*. <https://numpy.org/doc/stable/reference/generated/numpy.arange.html>. Accessed 2026-08-21. (Evenly spaced sample indices.)
4. Smith, Julius O. *Mathematics of the Discrete Fourier Transform (DFT), with Audio Applications*, 2nd ed. W3K Publishing, 2007. Free online edition: <https://ccrma.stanford.edu/~jos/mdft/>. Accessed 2026-08-21. (Sinusoids, sampling, and discrete-time signals.)
5. International Organization for Standardization. ISO 16:1975, *Acoustics — Standard tuning frequency (Standard musical pitch)*. <https://www.iso.org/standard/3601.html>. (A above middle C as 440 Hz; catalog record inspected 2026-08-21.)
