# Editorial guide

## Commitments

Connect musical experience, production practice, digital audio, DSP, computer science, and engineering without pretending they are identical. Introduce mathematics through something readers can hear, see, program, or measure: **hear → visualize → describe → calculate → implement**. Define terms, state units, distinguish analogy from equivalence, and never add artificial code to conceptual material.

“Tech music” is our organizing term, not an asserted genre. Do not rank electronic above traditional music. House is a recurring structural case study, not a boundary. Teach general DAW/synthesis principles before Ardour/Yoshimi implementation details.

## Definition of done for a substantive chapter

The chapter meets the [chapter contract](chapter-template.md), its runnable commands were executed, measurable claims have tests where practical, generated artifacts are reproducible, links pass the checker, and every factual source was actually inspected and recorded. Expected output must distinguish exact values from platform-dependent observations.
