# Roadmap

The [book index](../book/README.md) defines the complete chapter tree. Development follows the reader path **Listen → Compose → Produce → Inspect → Experiment → Debug → Program → Build**. First complete foundational listening/music chapters and digital-audio prerequisites; then production/DAW and synthesis; then DSP/MIDI and software architecture; finally integrate the programming projects and studio system. Future-facing chapters require especially careful, current research.

A chapter moves from `planned` to `draft` only with inspected sources, then to `executable` after examples and tests run, and to `reviewed` after musical, technical, editorial, and link review.
