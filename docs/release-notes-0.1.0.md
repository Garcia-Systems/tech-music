# Tech Music 0.1.0 release-candidate notes

This candidate integrates Parts I–XII into one navigable executable-textbook
sequence: 307 chapters, thirteen labs, separated exercises and solutions,
educational Python modules, and 97 tests. The release audit adds a complete TOC,
learning and reader paths, terminology and glossary references, reproducibility
and contribution policies, and automated structural validation.

This is not a 1.0 declaration. External software, hardware, listening, and full
reference-availability passes remain documented in the [release checklist](release-readiness.md).
