# Chapter 307 — What Should We Build Next?

## Model

Possible next builds and prerequisites: synth plugin (V, VII, IX, X); sequencer or MIDI controller (VIII–XI); adaptive game soundtrack (II, III, VIII–XII); visualization/audio analysis (VI, VII, X); collaborative server (VIII–XII); ML classifier or assisted sound designer (V–VII, X, XII); live system (III–XI). The next textbook task is a separate whole-book editorial, executable, citation, navigation, and release-readiness audit.

## Engineering questions

- What inputs, state, parameters, and versions determine the result?
- Which decision is fixed, sampled, learned, or left to a person?
- What invariant can software test, and what judgment requires a listener?
- What failure evidence and recovery control should the interface expose?

## Connection to the book

Parts II and VIII supply musical/event vocabulary; Parts V–VII render and process sound; Parts IX–XI supply scheduling, persistence, validation, and hardware boundaries.
