# Part III — Building Electronic Music

Part II supplied musical components. Part III uses one deliberately small, house-derived case study to build **silence → pulse → drums → bass → harmony → synth → texture → variation → sections → arrangement → complete track**. House is a recurring example, not a definition of tech music.

## Reproduce the part

```bash
python -m tech_music.production
pytest tests/test_production.py
```

Generated WAV files are intentionally ignored; the two compact SVGs may be reviewed and versioned. Listen at a comfortable level. The source never claims that automated checks can judge taste.
