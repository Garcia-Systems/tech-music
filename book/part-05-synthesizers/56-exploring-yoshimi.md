# Chapter 56 — Exploring Yoshimi

Yoshimi is a real software synthesizer used here only after the general model. Locally inspected Ubuntu metadata identifies package 2.3.2 as a software synthesizer originally based on ZynAddSubFX2 and points to the Yoshimi project homepage. The official manual and repository could not be reached, so this draft does **not** claim a verified list of engines, oscillator/filter/envelope mappings, effects, patch behavior, MIDI controls, or architecture. Those are the specific topics a connected follow-up should map to the general concepts from Chapters 40–55.

**Environment report (2026-08-21).** `command -v yoshimi` returned no executable, so no UI, audio, or MIDI workflow was executed. For a reproducible external lab: install the distribution package, start its documented executable, connect MIDI/audio using the host audio system, load a bundled instrument, play one note, change one oscillator/envelope/filter parameter, save under a new name, and record exact Yoshimi version and backend. These steps are **unexecuted here** and UI labels must be checked against the installed manual.

The package fact above was checked against local archive metadata; official pages were attempted but not inspected. The source note records commands and limitations. This is a bounded case-study plan, not a Yoshimi manual.
