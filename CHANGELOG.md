# Changelog

All notable project-level changes are summarized here. The project follows
semantic versioning for its executable package while the manuscript remains a draft.

## [0.1.0] — 2026-08-21 (release candidate)

- Established the music/listening foundation and completed Parts I–III.
- Added DAW, synthesis, digital-audio, DSP, MIDI, software-architecture,
  programming, workstation, and generative/adaptive Parts IV–XII.
- Built dependency-free educational systems, reproducible labs, separated
  debugging solutions, and property-focused automated tests.
- Completed a whole-book integration pass: 307-chapter structural validation,
  master navigation, reader paths, terminology, glossary, quick reference,
  executable inventory, release checklist, and generated-artifact enforcement.
