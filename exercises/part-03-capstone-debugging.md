# Part III capstone debugging challenge

Create a copy of the score containing five faults: percussion start `2.6`; one bass pitch `24`; chord intervals `(0,4,7)`; bass in the intro; and output samples multiplied beyond the safe range. Do not edit the working source in place.

For each category—timing, pitch, harmony, arrangement, level—submit: **Symptom → Evidence → Hypothesis → Investigation → Root Cause → Fix → Verification**. Use listening plus the event/grid/arrangement/sample evidence appropriate to the claim. A valid WAV is not proof of intended music.
